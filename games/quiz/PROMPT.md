# Five-question quiz

Build a browser game: Riverbend Club Quiz.
Recipe: five-question quiz.
One round: start → play → result → restart.
Main control: answer.

## Brief

- Player answers one question at a time, sees feedback, then Next
- Five questions, then score out of five and Play again
- One answer scores once
- No login, no server, no leaderboard
- Single HTML/CSS/JS page is fine
- After a round, Play again must reset all round state

Win / lose / draw must be visible on screen as a final score.
